  অর্ডার নম্বর, স্ট্যাটাস, আইটেম, টোটাল, তারিখ)

    - মার্চেন্ট রেজিস্টার করা থাকলে → তার নাম দিয়ে বাটন (merchant panel-এ যায়)
    - না থাকলে → "Merchant হন" বাটন (form খোলে)

  "Admin Panel" বাটন পাবেন — আগে যেটা ছিল সেটাই ফিরিয়ে আনা হয়েছে

-----------------------------------------------------
1. মার্চেন্ট রেজিস্ট্রেশন ফর্ম (profile.html)
-----------------------------------------------------
"Merchant হন" সবুজ বাটনে ক্লিক করলে আলাদা form আসবে:
   (1) নাম / দোকানের নাম
   (2) ঠিকানা          ← নতুন
   (3) মোবাইল নম্বর
   (4) ইমেইল
   (5) NID দুইটি ছবি — সামনের (front) + পিছনের (back) দিক

নোট: ওয়েবসাইট নিজে থেকে যাচাই করতে পারে না যে ছবিটা আসল বাংলাদেশ
NID-এর কি না — এটা কোনো সাইটই পারে না। তাই নিরাপত্তার ব্যবস্থা হলো:
প্রোডাক্ট রিকোয়েস্ট approve করার সময় অ্যাডমিনের সামনে মার্চেন্টের NID
দুইটির ছবি দেখাবে — আপনি ভালো করে দেখে approve করবেন।
ছবি শুধু image file, সর্বোচ্চ 5MB। আগে single NID দেওয়া মার্চেন্টের
(আপনার) পুরনো ছবিও দেখা যাবে (fallback আছে)।

-----------------------------------------------------
2. মার্চেন্ট প্যানেলে ৩টা নতুন অপশন (merchant.html)
-----------------------------------------------------
এখন sidebar-এ মোট ৭টা ট্যাব:
   • ড্যাশবোর্ড          → প্রোডাক্ট/অপেক্ষমাণ/অর্ডার/ব্যালেন্স stat
   • প্রোডাক্ট যোগ      → (আগের মতো, কিন্তু এখন রিকোয়েস্ট — নিচে দেখুন)
   • আমার প্রোডাক্ট     → স্ট্যাটাস badge সহ (অপেক্ষমাণ/অনুমোদিত/বাতিল)
   • আমার অর্ডার        ← নতুন: আপনার প্রোডাক্ট যেসব অর্ডারে আছে,
                          কাস্টমারের নাম/ফোন/ঠিকানা/আইটেম/টোটাল/স্ট্যাটাস
   • আমার ইনকাম         ← নতুন: মোট আয় (ডেলিভারড), SB BRAND SHOP 5%
                          কমিশন বাদ, তোলার পর, চলমান রিকোয়েস্ট বাদ
                          = হাতে থাকা ব্যালেন্স
   • পেমেন্ট রিকোয়েস্ট  ← নতুন: bKash / Nagad / Bank — অ্যাকাউন্ট নম্বর
                          + অ্যাকাউন্টধারীর নাম দিয়ে টাকা তোলা আবেদন
                          (ব্যালেন্সের বেশি দিলে কাজ করবে না)
   • ক্যাটাগরি রিকোয়েস্ট → (আগের মতোই)

ইনকামের হিসাব: শুধু ডেলিভারড অর্ডারের আপনার প্রোডাক্টের (দাম×পরিমাণ)।
ডেলিভারি চার্জ কখনো আপনার ইনকামে যোগ হয় না।

-----------------------------------------------------
3. মার্চেন্ট প্রোডাক্ট এখন সরাসরি শপে দেখাবে না
-----------------------------------------------------
মার্চেন্ট প্রোডাক্ট add করলে status = "pending" (রিকোয়েস্ট)।
শপে (index/product) pending বা rejected প্রোডাক্ট কিছুতেই দেখা যাবে না
(সোয়াপ পেজেও ব্লক করা আছে)। শুধুমাত্র:
   - admin যোগ করা প্রোডাক্ট (status ছাড়া) → সরাসরি লাইভ
   - admin approve করা প্রোডাক্ট (status: approved) → লাইভ

-----------------------------------------------------
4. Admin প্যানেলে ৩টা নতুন ট্যাব (admin.html)
-----------------------------------------------------
এখন sidebar-এ মোট ১১টা ট্যাব, নতুনগুলো:
   • প্রোডাক্ট রিকোয়েস্ট  ← মার্চেন্টের প্রোডাক্ট আবেদন
      - মার্চেন্টের NID দুইটির ছবি ঝুলছে (ক্লিক করলে বড় হবে)
      - "✅ অনুমোদন" → status approved → সাথে সাথে শপে দেখা যাবে
      - "❌ রিজেক্ট" → status rejected → শপে দেখা যাবে না
      - নিচে "সম্পন্ন রিকোয়েস্ট" লিস্টও থাকবে
   • ক্যাটাগরি রিকোয়েস্ট  ← All Merchants-এর ভিতর থেকে আলাদা ট্যাব হলো
      (approve/reject ফিচার আগের মতোই)
   • পেমেন্ট রিকোয়েস্ট    ← মার্চেন্টের টাকা তোলা আবেদন
      - bKash/Nagad/Bank, অ্যাকাউন্ট নম্বর, পরিমাণ, তারিখ
      - টাকা পাঠানোর পর "✅ সফল (টাকা দেওয়া হয়েছে)" চাপুন
      - ব্যর্থ হলে "❌ বাতিল" — বাতিল করলে অংকটা মার্চেন্টের
        ব্যালেন্সে ফিরে যাবে

-----------------------------------------------------
5. All Merchants-এ নামে ক্লিক
-----------------------------------------------------
মার্চেন্টের রেজিস্ট্রেশন info (নাম, ফোন, ইমেইল, ঠিকানা, NID দুইটি
ছবি) দেখা যাচ্ছে। <b>নামে ক্লিক করলে</b> মোটামুটি detail modal আসবে:
   • মোট প্রোডাক্ট
   • মোট অর্ডার (তার প্রোডাক্ট)
   • মোট আয় (ডেলিভারড)
   • SB কমিশন (5%)
   • তোলার পর (সফল রিকোয়েস্ট)
   • চলমান রিকোয়েস্ট
   • মোট ব্যালেন্স
   • NID ছবি (ক্লিক করে বড় করে দেখা যায়)

-----------------------------------------------------
6. ভাষা / Language (Settings)
-----------------------------------------------------
Admin > Settings-এ নতুন "🌐 ভাষা" অপশন:
   • English (ডিফল্ট) — সবাই আগেই ইংরেজি দেখবে
   • বাংলা (Bangla)
ডেফল্ট English। অ্যাপ খুললেই Settings থেকে ভাষা পড়া হয়।
এটা কাস্টমার-দেখা পাতাগুলোতেই কাজ করবে (হোম, প্রোডাক্ট, কার্ট,
অর্ডার, প্রোফাইল, লগইন)। Admin/Merchant প্যানেল বাংলায়ই থাকবে।
(নতুন ফাইল lang.js-এ দুই ভাষার সব টেক্সট আছে)

-----------------------------------------------------
7. মোট আয় (Admin ড্যাশবোর্ড)
-----------------------------------------------------
এখন "মোট আয় (৳)" শুধু প্রোডাক্টের দামই গণনা করে
(ডেলিভারড অর্ডারের items: দাম×পরিমাণ)।
ডেলিভারি চার্জ আলাদা stat-এ দেখাবে: "ডেলিভারি আয় (৳)"।
ড্যাশবোর্ডে এখন মোট ৮টা stat:
   মোট প্রোডাক্ট / মোট অর্ডার / অপেক্ষমান অর্ডার / মোট আয়
   ডেলিভারি আয় / মোট মার্চেন্ট / পেন্ডিং প্রোডাক্ট রিকোয়েস্ট
   / পেন্ডিং পেমেন্ট রিকোয়েস্ট
(Sidebar-এ pending product request ও payment request-এর লাল badge আছে)

DEPLOY করার নিয়ম
=====================================================
1. এই ১১টা ফাইল hosting ফোল্ডার-এ (sb-brand-shop original/sb-brand-shop/
   এর ভিতরের folder) পুরনো ফাইলের জায়গায় copy করুন।
   lang.js নতুন — একই জায়গায় রাখুন।

2. Firestore Rules আপডেট (বাহ্যিক প্রয়োজন!):
   Firebase Console → Firestore Database → Rules tab
   → আগের rules সব delete করে firestore-rules.txt-এর content paste
   → Publish
   নতুন rules-এ paymentRequests collection-এর আয়ত্ত আছে।

3. firebase deploy --only hosting

4. Test করার ধাপ:
   a. কোনো নতুন account-এ লগইন → Profile → "Merchant হিসেবে
      রিজিস্টার করুন" → নাম, ঠিকানা, ফোন, ইমেইল, NID দুই ছবি দিন
   b. Merchant panel-এ ঢুকুন → "প্রোডাক্ট যোগ" দিয়ে একটা প্রোডাক্ট
      পাঠান → "আমার প্রোডাক্ট"-এ "অপেক্ষমাণ" badge দেখবেন
      → শপ-এ দেখা যাবে না (নিশ্চিত করুন)
   c. Admin-এ ঢুকুন (sadikul.pcml@gmail.com) → "প্রোডাক্ট রিকোয়েস্ট"
      → NID ছবি দেখে "অনুমোদন" → এখন শপ-এ দেখা যাবে
   d. Merchant panel-এ "আমার ইনকাম" ও "পেমেন্ট রিকোয়েস্ট" চেক করুন
   e. Admin-এ "পেমেন্ট রিকোয়েস্ট" → "সফল" করে দিন → ব্যালেন্স কমে
      যাওয়া চেক করুন
   f. All Merchants-এ মার্চেন্টের নামে ক্লিক → detail দেখুন
   g. Settings-এ ভাষা "বাংলা" করুন → হোমপেজ বাংলায় হবে;
      "English" করলে ইংরেজি (ডিফল্ট)
